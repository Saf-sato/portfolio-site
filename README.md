# Fumi Sato Portfolio

ポートフォリオサイトです。
フロントエンドを中心に、HTML / CSS / JavaScript を用いた Web 制作を行っています。

## 概要

本サイトは、自身の制作実績・スキル・プロフィールをまとめたポートフォリオサイトです。
落ち着いたトーンと余白設計を意識し、情報量を抑えたシンプルなレイアウトにしています。見やすいポートフォリオサイトを目指しました。
情報を整理し、閲覧者が迷わない構成を意識しています。
